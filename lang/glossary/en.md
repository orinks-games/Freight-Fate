# Glossary: the English terms

Each word below names one thing in the game, and the game always uses the
same word for it. A blind player builds the game from what they hear, so a
second word for the same thing sends them back to work out whether it is
something new. Every translation keeps the same promise: pick one word for
each term, write it in your language's glossary file
(`lang/glossary/<code>.md`), and use it every time.

The full list, with the words to avoid and why, is the "Spoken vocabulary"
table in [docs/ontology.md](../../docs/ontology.md). This page is the short
list that comes up in almost every screen.

## Never translate

- **Place names**: cities, towns, states, highways ("I-80", "US 30"),
  streets, rivers, parks, truck stop chains, carriers and companies.
- **Key names** as the help reads them: Enter, Escape, Space, Tab,
  Backspace, Page Up, Page Down, Home, End, the F keys, letter keys, Shift,
  Control, Alt, and the controller's button names.
- **Song and station titles**, radio clips, and anything in quotes that
  names a recording.
- **Brand and product names**: Freight Fate, orinks.net, CAT Scale, TWIC,
  CDL, NVDA, JAWS, VoiceOver, Discord.
- **Numbers.** Keep every digit exactly as written. "55" stays "55".
- **Placeholders** in braces, like `{city}` or `{distance}`. Move them
  wherever your grammar needs them, but keep the name inside the braces
  exactly as it is.

## Core terms

| English | What it means |
| --- | --- |
| job | The contract to haul something. Not the freight itself. |
| cargo, the load | The freight on the trailer. |
| dispatch board | The list of jobs on offer. |
| call dispatch | Asking the carrier's dispatcher for help during a run. |
| dispatch trust | How far dispatch will work with you right now. |
| truck | The vehicle. |
| your assigned truck | The tractor a carrier gave you. |
| fleet | The set of carrier trucks dispatch assigns from. |
| trailer | What the truck pulls. |
| tank trailer | The trailer liquid bulk rides in. |
| leg | One city-to-city stretch of road. |
| run | One drive, start to finish. |
| home terminal | The city a career starts from. |
| carrier | The trucking company you drive for. |
| company driver | A driver employed by a carrier. |
| owner-operator | A driver who owns the truck. |
| leased-on | An owner-operator hauling under a carrier's authority. |
| own authority | An owner-operator with their own operating authority. |
| settlement | The money paid out when a job is delivered. |
| deadline | When the load is due. |
| stop | A truck stop, travel center or other place to pull in. |
| truck stop | A full-service stop for trucks. |
| travel center | A large truck stop. |
| rest area | A public parking area beside the highway. |
| weigh station, the scale | The roadside inspection facility. |
| facility gate | The entrance where a drive ends. |
| destination exit | The highway exit for the delivery. |
| rank | A band of career levels. |
| credential | Any license or training, taken together. |
| endorsement | A letter on the commercial license earned by a written test. |
| certificate | Training a carrier issues. Not on the license. |
| hours of service | The legal driving clock as a whole. |
| driving time left | What remains of the 11-hour driving clock. |
| at the wheel | Driving time already spent this shift. |
| duty window | The 14-hour clock that starts when you go on duty. |
| break | The 30 minutes off the wheel the law requires. |
| clock | The in-game time of day. |
| lane keeping | How much of the lane-holding work the truck does. Values: full, partial, off. |
| curve assistance | The assist that takes a mapped bend for you. |
| adaptive cruise | Cruise control that keeps a following gap. |
| following gap | Room adaptive cruise leaves to the vehicle ahead, in seconds. |
| engine brake, jake | The engine's retarder. "Jake" only in short control feedback. |
| descent control | The assist that holds a safe speed on a downgrade. |
| grade | A sustained slope, with its percent: uphill grade, downhill grade. |
| traffic | Vehicles around you now. |
| delays, road reports | Incidents reported on the road ahead. |
| lane open, lane blocked | Whether the next lane over has room. |
| passing | Lane keeping moving around a slow vehicle. |
| hazard | Something in the truck's path that needs a reaction now. |
| stopping distance | Road the truck needs to stop from here. |
| low bridge | A posted height restriction. |
| weight limit | A posted weight restriction. |
| exit speed | The speed a ramp's curve is built for. |
| ramp curve | The bend at the end of an exit lane. |
| safe turnaround | The loop back after missing an exit or a turn. |
| yield | Give way at a ramp end. |
| citation | One booked ticket on the driving record. |
| serious violation | An offense that counts toward losing the license. |
| major offense | An offense heavy enough to disqualify the license outright. |
| driving record | Citations and violations on the license. |
| safety record | How interesting you look to an inspector. |
| reputation | How much dispatch and shippers trust you, 0 to 100. |
| roadside inspection | An officer checking the truck or the papers. |
| out of service | The truck may not be driven until something is fixed. |
| reduced power | The first damage band: the engine holds back. |
| limp mode | Reduced power plus a road-speed cap. |
| roadside repair | The call-out that gets an out-of-service truck moving. |
| roadside rescue | The call-out that brings fuel to an empty tank. |
| fuel range | How far the fuel in the tank reaches. |
| debt, what you owe | Everything the driver is behind by. |
| balance owed | Charges a settlement could not cover. |
| keyboard shortcut | A driving control moved to another key. |
| controller button | The same on a game controller. |
| driving speech | How much the road tells you. Values: standard, quiet, urgent only. |
| driving mode | The pacing. Values: relaxed, standard, real time. |
| roadside chatter | Color between navigation cues: parks, rivers, passes, museums, billboards. |
| place callouts | Town names along the road. |
| message review | The keys that replay recent spoken lines. |
| achievement | A badge earned by play. |
| category | A group of related achievements. |
| drivers on duty | Other players out working right now. |
| driver profile | One driver's public page. |
| activation code | The short code a player types into a browser to connect. |
| backed up, backup | A career's copy on orinks.net. |
