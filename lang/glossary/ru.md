# Glossary: Russian

The game addresses the player as "вы", always lowercase ("У вас 2 часа
вождения"). The register is plain, friendly and spoken: a co-driver talking
in the cab, not a manual. Short sentences, everyday words, no abbreviations a
screen reader would spell out.

Units: distances stay in the unit the game uses, miles and feet or
kilometers and meters. Only the unit word is translated; the numbers never
change. Key names (Enter, Escape, Space, Tab, Page Up, F1...) and place names
stay in English.

Plurals: the game supports `{count:one|few|many}` choices (see "Plurals" in
`lang/README.md`): one for 1, 21, 31; few for 2 to 4, 22 to 24; many for 5 to
20, 25. Every unit after a number uses them, for example
`{count} {count:миля|мили|миль}`, `{count:фут|фута|футов}`,
`{count:километр|километра|километров}`, `{count:час|часа|часов}`.
